# ai-eng-notlar

Sıfırdan AI engineer olma yolunda günlük öğrenme notlarım. 12 hafta, 60 gün, günde 1–2 saat.

Planın tamamı: [ogrenme-plani.md](ogrenme-plani.md)

## Nasıl çalışıyor

Her gün tek konu. Önce kendi başıma öğreniyorum (doküman, video, deney), sonra 3–5 cümlelik not yazıyorum, sonra Claude'a anlatıp test oluyorum. Yanlışlar düzeltiliyor, eksikler tamamlanıyor.

## Klasör yapısı

```
ogrenme-plani.md        12 haftalık plan, gün gün
hafta-XX/gun-YY-konu.md günlük notlar
haftalik-ozet/          her Cuma 10 satırlık özet
kod/                    o gün yazılan script ve deneyler
```

## Günlük not şablonu

```markdown
# Gün YY — Konu

**Ne öğrendim:** 3–5 cümle, kendi kelimelerimle.

**Ne yaptım:** çalıştırdığım komut / yazdığım kod / yaptığım karşılaştırma.

**Projede nerede kullanacağım:** 1 cümle.

**Anlamadıklarım:** soru listesi, Claude'a sorulacak.
```

## Kural

Bu repo kişisel öğrenme içindir. Şirkete ait doküman, müşteri bilgisi, sunucu adresi, gerçek iş verisi buraya girmez. Egzersizler uydurma veya herkese açık verilerle yapılır.
